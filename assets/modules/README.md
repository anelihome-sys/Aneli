# Фотографии модулей

Сюда кладутся шесть снимков — по одному на модуль программы. Они появляются
в `praktikum-dokument.html` и в собранном из него PDF автоматически: пока файла
нет, на его месте стоит подпись с описанием нужного кадра.

| Файл | Что на кадре | Какой навык показывает |
|---|---|---|
| `01.jpg` | Обмерный план и лазерная рулетка на объекте | Замеры и планировка |
| `02.jpg` | Коллаж концепции: палитра, фактуры, референсы | Создание концепции |
| `03.jpg` | Образцы камня, плитки и дерева в шоуруме | Подбор материалов и смета |
| `04.jpg` | Физический мудборд: ткани, фурнитура, фасады | Комплектация |
| `05.jpg` | Чертежи на объекте в стройке | Авторский надзор, работа с подрядчиками |
| `06.jpg` | Готовый интерьер в финальной съёмке | Завершение проекта, портфолио |

Требования: вертикальный кадр 4:5, не меньше 900×1125 px, JPEG.
Снимки с ваших собственных объектов — не сток: документ продаёт вашу практику.

После замены файлов откройте `praktikum-dokument.html` в браузере и нажмите
Ctrl+P → «Сохранить как PDF», чтобы пересобрать документ.
