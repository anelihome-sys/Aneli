# Документы

## Договор на разработку дизайн-проекта интерьера (Алматы, РК)

`Договор_дизайн-проект_интерьера_Алматы_шаблон.docx` — шаблон договора возмездного
оказания услуг на дизайн-проект (рабочие чертежи + 3D-визуализации).
Times New Roman, 14 пт, А4. Все переменные оставлены прочерками для заполнения.

Ключевые положения:
- раздел 4 — перечень услуг, НЕ входящих в предмет (авторский надзор, сопровождение,
  комплектация, сметы, лицензируемые разделы, согласование перепланировки);
- раздел 7 — два круга правок включены в стоимость, третий и последующие оплачиваются
  отдельно; переработка согласованных решений — дополнительные работы;
- приложения № 1–5: техническое задание, состав дизайн-проекта, график платежей,
  акт оказанных услуг, заявка на дополнительные работы.

### Пересборка файла

```bash
npm install docx
node documents/generate-contract.js "documents/Договор_дизайн-проект_интерьера_Алматы_шаблон.docx"
```
