# Экзаменационный тест · Дизайн интерьера (базовый уровень)

`interior-design-exam.pdf` — 5 вариантов по 15 вопросов + ключ ответов на отдельном листе.

- Вопросы перемешаны между вариантами, часть пересекается намеренно.
- Блоки: эргономика, санузлы, этапы проекта, материалы, работа с клиентом и договоры.
- Первые три вопроса каждого варианта — эргономика.

## Как пересобрать

```bash
python3 exam/build_exam.py            # соберёт exam/exam.html
/opt/pw-browsers/chromium --headless --disable-gpu --no-sandbox \
  --no-pdf-header-footer --print-to-pdf=exam/interior-design-exam.pdf exam/exam.html
```

Пул вопросов и правильные ответы — в начале `build_exam.py` (списки `ERG`, `SAN`, `ETAP`,
`MAT`, `BIZ`; последнее число в каждой строке — индекс правильного ответа).
Порядок вариантов ответа перемешивается автоматически, ключ пересчитывается сам.
