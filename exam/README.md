# Экзаменационный тест · Дизайн интерьера (базовый уровень)

| Файл | Содержание |
|---|---|
| `interior-design-exam.pdf` | Комплект 1 — варианты 1–5, по 15 вопросов + ключ ответов |
| `interior-design-exam-set2.pdf` | Комплект 2 — варианты 6–10, по 15 вопросов + ключ ответов |

- Блоки: эргономика, санузлы, этапы проекта, материалы, работа с клиентом и договоры.
- Первые три вопроса каждого варианта — эргономика.
- Комплект 1: 57 уникальных вопросов на 75 позиций, часть пересекается между вариантами.
- Комплект 2: 75 уникальных вопросов, повторов нет ни внутри комплекта, ни с комплектом 1.
- Порядок вариантов ответа перемешан для каждого варианта отдельно, ключ считается автоматически.

## Word

`docx/Экзамен_Вариант-01.docx` … `Экзамен_Вариант-10.docx` — по одному файлу на вариант
(01–05 — комплект 1, 06–10 — комплект 2). В каждом файле лист с вопросами и отдельный
лист с ключом ответов, который удаляют перед выдачей бланка.

```bash
cd exam
npm install docx          # один раз
python3 export_variants.py   # variants.json из обоих комплектов
node build_docx.js           # docx/Экзамен_Вариант-XX.docx
```

## Как пересобрать

```bash
cd exam
python3 build_exam.py     # комплект 1 -> exam.html
python3 build_exam2.py    # комплект 2 -> exam2.html
/opt/pw-browsers/chromium --headless --disable-gpu --no-sandbox \
  --no-pdf-header-footer --print-to-pdf=interior-design-exam.pdf exam.html
/opt/pw-browsers/chromium --headless --disable-gpu --no-sandbox \
  --no-pdf-header-footer --print-to-pdf=interior-design-exam-set2.pdf exam2.html
```

## Структура файлов

- `build_exam.py`, `build_exam2.py` — пулы вопросов (`ERG`, `SAN`, `ETAP`, `MAT`, `BIZ`)
  и сборка вариантов. Последнее число в каждой строке — индекс правильного ответа
  в исходном списке; порядок ответов на печати перемешивается, ключ пересчитывается сам.
- `layout.py` — общая вёрстка бланка и ключа. Параметры `fs`, `gap`, `lh` в `build_html`
  задают плотность набора: если вопросы станут длиннее и вариант перестанет помещаться
  на лист, уменьшайте `fs`.
